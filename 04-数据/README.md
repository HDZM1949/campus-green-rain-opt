# 数据说明与数据字典

## 三类数据

1. `公开资料/` —— 暴雨强度公式、台风事件、气候统计、文献参数（每份资料注明来源与获取日期）
2. `场地/` —— 卫星底图（Esri World Imagery，论文需注明来源）、`bounds.json`（经纬度范围，用于像素↔坐标换算）、`地块调查表.csv`、现场照片
3. `实测/` —— 温度实测（`温度记录表.csv`）等

## 数据字典（随项目更新）

| 变量/符号 | 含义 | 单位 | 取值/来源 | 状态 |
|---|---|---|---|---|
| A_j | 地块 j 面积 | m² | 场地测绘/影像数字化 | 待采集 |
| P_T | 重现期 T 的设计雨量 | mm | 暴雨强度公式 × 历时 | 公式待核实 |
| CN_j | 地块 j 径流曲线数 | — | 手册/文献 + 灵敏度 | 待定 |
| c_{j,k} | 地块 j 采用类型 k 的造价 | 元 | 定额/文献/询价 | 待采集 |
| ΔQ_{j,k} | 径流削减量 | m³ | SCS-CN 计算 | 建模阶段 |
| ΔT_{j,k} | 降温收益 | ℃·m² | 实测 + 文献系数 | 待标定 |
| B | 总预算 | 元 | 情景设定 | 待设定 |
| x_{j,k} | 决策变量（0/1） | — | 优化模型 | 建模阶段 |

## 命名与记录规范

- 照片：`PH_序号_地点_内容.jpg`，并在日志中登记编号
- 表格：原始数据只增不改；修正另起"修订值"列并注明原因
- 引用：每条数据记录"来源 + 获取日期 + 链接/页码"
