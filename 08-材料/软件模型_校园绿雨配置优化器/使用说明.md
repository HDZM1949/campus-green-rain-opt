# 校园"绿-雨"配置优化器 · 使用说明

> 一款面向校园（可扩展至社区、园区）的绿色基础设施配置优化工具：
> 给定改造预算，回答"绿地 / 透水设施**放在哪、做成什么**"，
> 使**暴雨径流削减**与**夏季降温**两项服务收益最大化。
> 案例：晋江市季延中学本部（12 个候选地块，校园数字化面积 84,599 m²）。

---

## 1. 软件内容

| 文件 | 说明 |
|---|---|
| `optimizer.py` | 主程序（命令行界面，一键运行） |
| `core.py` | 核心库（产流计算 + 双目标优化 + 参数扰动接口） |
| `data/地块参数表.csv` | 地块数据（编号 / 名称 / 面积 / 下垫面类型 / 现状 CN） |
| `data/设计暴雨表.csv` | 设计暴雨表（重现期 × 历时 → 事件雨量） |
| `使用说明.md` | 本文件 |
| `演示与录屏.md` | 演示视频分镜脚本与命令清单 |

## 2. 运行环境

- Windows + Python 3.10 以上（开发环境：Python 3.14）
- 依赖：`numpy`、`scipy`（安装：`pip install numpy scipy`）
- 无需联网；全部计算在本机完成，精确求解（MILP），秒级出结果

## 3. 快速开始（在软件目录下打开 cmd）

```bat
chcp 65001                                :: 避免中文乱码（仅 cmd 需要）
python optimizer.py                       :: 演示模式：预算 100 万元，输出完整报告
python optimizer.py --budget 200          :: 指定预算（万元）
python optimizer.py --mode binary         :: 整块实施（0-1）模式（默认：面积比例）
python optimizer.py --scenario 263.9      :: 情景评估：事件雨量 263.9 mm（杜苏芮·安海）
python optimizer.py --scan                :: 预算扫描（50/100/200/400 万元）摘要
python optimizer.py --export 结果         :: 导出 Pareto 前沿与三档方案 CSV
python optimizer.py --list                :: 打印地块与措施参数表
```

## 4. 参数说明

| 选项 | 默认值 | 说明 |
|---|---|---|
| `--budget` | 100 | 改造预算（万元） |
| `--mode` | frac | `frac` = 面积比例（连续规划）；`binary` = 整块实施（0-1 规划） |
| `--scenario` | — | 事件雨量（mm），覆盖主设计情景（3 年一遇 60 min = 55.1 mm） |
| `--eps` | 41 | ε-约束扫描点数（越大前沿越细，求解时间略增） |
| `--scan` | 关 | 输出四档预算扫描摘要 |
| `--export` | — | 导出目录（生成"Pareto前沿.csv""三档方案.csv"） |
| `--list` | 关 | 打印地块与措施参数表 |

## 5. 输出解读

- **【1】现状评估**：现状产流 Q₀ 与等效径流系数（回答"现状风险多大"）
- **【2】优化求解**：Pareto 前沿规模与范围（ΔQ₃ = 径流削减量，m³；ΔT = 降温收益，℃·m²）
- **【3】三档方案**：径流优先型 / 均衡型 / 降温优先型（含投向明细与造价）
- **【4】模式对照**：整块实施相对面积比例模式的效率损失
- **【5】结论提示 / 【6】预算扫描**（`--scan`）
- 若前沿退化为单点：提示"两目标共向"（如极端暴雨情景）

## 7. 迁移到其他学校 / 社区（推广用法）

1. **替换 `data/地块参数表.csv`**：按自己场地填写
   （列：编号, 名称, 面积_m2, 现状类型, CN_现状, 备注；`现状类型` 取值：硬化 / 球场 / 草地 / 林地 / 待核；
   另保留一行 `编号=REM` 表示"其余区域（建筑与道路等）"，只参与现状产流计算、不参与改造）
2. **替换 `data/设计暴雨表.csv`**：若不在泉州，用当地暴雨强度公式重算雨量表
   （公式形式与程序：见项目 `05-模型/m1_design_storm.py`；本机已参数化，可一键替换）
3. **如需调整措施参数**（CN / 单价 / 降温系数）：修改 `core.py` 顶部的"参数区"（有中文注释）
4. 重新运行 `python optimizer.py` 即可（无需其他改动）

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 中文乱码（cmd） | 先执行 `chcp 65001`，或改用 Windows Terminal |
| `ModuleNotFoundError: scipy` | 执行 `pip install numpy scipy` |
| 报告显示"无可行解" | 预算过小或数据异常；检查 `data/` 两个 CSV 格式 |
| 求解很慢（>10 s） | 提高 `--eps` 会变慢；默认 41 点通常 1–3 秒 |

## 9. 方法与局限

- **方法链**：设计暴雨（事件口径）→ SCS-CN 产流 → 文献降温系数 → 双目标 0-1 规划（ε-约束 + scipy.milp / HiGHS 精确求解）→ Pareto 前沿 → 三档方案
- **局限**：未含地下管网与地形；造价与降温系数为静态经验值；地块面积为影像数字化近似值（±5–10%）。完整讨论见论文 v1 第 7.6 节。
