## 全项目规则

1. **数据可溯源**：每个数字都要有来源（文件 / 网页 / 检索记录）；不编造、不用杜撰样张数据。
2. **日期口径**：D1 = 2026-09-24 启动（日期版日程见 `03-日程与分工.md`；D21 = 10-14）；每完成一步当日更新科学日志。
3. **日志即写即存**：做完即记，包含失败与修改过程（评分点）。
4. **图件规范**：矢量 PDF + 300dpi PNG 预览；PDF 字体可编辑（fonttype=42）。
5. **命名规范**：数据 `序号_类型_内容`；图 `T编号_名称`；代码 `m#_名称.py`。
6. **工作区精简**：临时文件（中间图、一次性脚本、废弃版本）用后即删；目录只保留在用文件。
7. **纯论文口径**：不制作实物、不做实地测量；全部参数与数据来自公开资料/文献，并在日志与数据字典中记录来源。
